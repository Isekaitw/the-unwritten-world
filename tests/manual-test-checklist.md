## 測試前
- [ ] GitHub repository 根目錄存在 `index.html`。
- [ ] `index.html` 引用的 `./css/main.css` 和 `./js/main.js` 路徑正確。
- [ ] GitHub Pages 已設定為 `main` 分支的 `/(root)`（若要測試公開網站）。

## 功能測試
- [ ] 開啟頁面時顯示「零界紀元」標題畫面。
- [ ] 點擊「開始探索」後，標題畫面消失並顯示潮痕灘。
- [ ] 點擊「調查潮痕標記」後，對話面板顯示。
- [ ] 點擊「明白了」後，對話面板關閉。
- [ ] 點擊「返回標題」後，可回到標題畫面。
- [ ] 使用鍵盤 Tab 可聚焦主要按鈕；Escape 可關閉對話面板。

## 手機／平板檢查
- [ ] 直向畫面沒有主要按鈕被裁切。
- [ ] 橫向畫面仍可讀取場景與互動文字。
- [ ] 熱點可用手指操作，不依賴滑鼠懸停。
- [ ] 啟用「減少動態效果」偏好時，動畫已降低。
