## 角色移動抖動回報追蹤（2026-10-23）
- 初次回報：角色正常走動時偶爾抖動，位置不固定，輸入方式未確認。
- 第一輪修正：角色位置改以 `translate3d()` 更新。使用者實測後回報：抖動仍存在，但頻率變快、範圍變小；因此第一輪修正未能解決問題。
- 第二輪回報：抖動仍然存在，使用者希望同時按下 W+A 時角色直線往左上移動。
- 方向修正：W=上、A=左、S=下、D=右；W+A 為左上對角線。對角線輸入由 `getInput()` 正規化，速度不應高於直線移動。
- 第三輪實測回報：角色仍抖動，且斜向移動呈現「上、左」交替的階梯感；前一輪將繪製座標取整數並未解決問題，且可能直接造成階梯式斜移。
- 驗收仍待執行：空曠區連續直線移動、鏡頭跟隨區移動、貼近障礙物滑行、快速切換方向；鍵盤與觸控分別測試。記錄裝置／瀏覽器／輸入方式，並觀察是只有角色還是背景也一起抖動。
- 本輪修正尚未在實際瀏覽器、手機／平板或 GitHub Pages 執行驗證；不能標記為已解決。

- 第四輪修正：移除每幀對角色與鏡頭座標的 `Math.round()`，讓繪製位置保留小數 CSS 像素；物理輸入仍在同一更新週期同時計算 X/Y，W+A 應連續朝左上移動。這是針對階梯感的修正假設，抖動是否改善仍待使用者實測。
