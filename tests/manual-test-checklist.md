## 桌面瀏覽器功能測試
- [ ] 開啟頁面先顯示標題畫面。
- [ ] 按「開始探索」進入測試區；出生點不與障礙重疊。
- [ ] WASD 四方向可移動，方向鍵四方向可移動；放開按鍵即停止。
- [ ] 對角線速度已正規化；不同影格率下移動速度合理。
- [ ] 角色從障礙至少兩個方向接近時會被阻擋，且能沿另一軸滑動。
- [ ] 角色不能穿出 1600×1000 世界邊界。
- [ ] 鏡頭跟隨角色；能探索初始視窗外區域；世界邊緣不露出場景外空白。
- [ ] 在互動物件範圍外按 E／Enter 不觸發；靠近標記後互動顯示描述。
- [ ] 靠近秘密後互動可發現 `test_secret_tide_echo`；同一局再次靠近不會重複發現。
- [ ] 啟動測量機關後，通路外觀改變且可實際走過原障礙位置。
- [ ] Escape 可關閉對話；返回標題再開始不會重複移動或事件。
- [ ] 視窗失焦／切換分頁後輸入會清除，不會卡住移動。
- [ ] 無新增 Console 未處理錯誤。

## 手機／平板觸控測試
- [ ] 方向控制按住可持續移動；鬆手、pointercancel、失去 pointer capture 後停止。
- [ ] 手指離開控制區／切換 App／視窗失焦後不會持續移動。
- [ ] 可同時或快速連續輸入方向，斜向移動合理。
- [ ] 互動按鈕與方向控制分離；沒有目標時互動按鈕停用。
- [ ] 直向與橫向畫面下，角色、方向控制、互動按鈕和狀態提示可使用。
- [ ] 安全區域、文字大小及按鈕尺寸合理，非控制區仍可正常捲動／點擊。
