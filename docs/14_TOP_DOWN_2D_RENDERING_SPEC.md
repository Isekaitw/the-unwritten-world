# 俯視 2D 自然地貌與場景渲染技術規格

> 現行開發方向與分階段技術規格；不是已完成架構或驗收報告。
> 決策日期：2026-11-11

## 1. 目標
採正俯視 2D（Top-down 2D），建立能呈現自然地貌的地圖：不規則海岸、沙灘、河流、湖泊、水域、草地、泥地、岩石、洞穴、懸崖邊界與自然通道。不要求 2.5D、等角投影、視差、局部 3D 或遊戲引擎。保留 HTML、CSS、原生 JavaScript、Canvas 2D、JSON、GitHub Pages、零預算與既有可重用遊戲核心。

## 2. 核心原則
- 模擬與呈現分離：繪圖不能決定移動、碰撞、水域狀態、互動或謎題結果。
- 世界座標一致：路徑、碰撞、可通行區、互動範圍及材質以同一世界座標關聯。
- 外觀與物理分離：美術輪廓可比碰撞幾何細緻；碰撞可用誤差受控的折線近似，但不能封住洞口或改變凹形拓樸。
- 自然輪廓優先：不以矩形拼接或單純圓角作為所有地形的最終表達。
- 增量可回退：先完成自然地貌垂直切片，不全面重寫。
- 本規格是目標，不代表通用曲線資料模型、曲線碰撞與材質系統已完成。

## 3. 視角與座標
正俯視、正交 2D；地圖 x/y 世界座標直接映射到畫面，不採等角投影或透視傾斜。角色移動、碰撞與相機沿用現有世界座標語義。地圖可超出視窗，由相機跟隨角色。懸崖、洞穴與岸線以俯視輪廓、材質、色彩及局部 2D 效果表達，不使用高度軸或視差作為必要條件。

## 4. 共用 Path Geometry
規劃共用路徑描述，支援 Move／Line、二次貝茲曲線、三次貝茲曲線、圓弧／橢圓弧及 Close。封閉路徑描述地形區域；開放路徑描述河岸、懸崖邊界或道路邊緣。渲染器可轉成 Canvas 2D Path；碰撞系統使用獨立離散化結果，不讀取 Canvas 像素。

### 曲線碰撞近似
- 曲線細分／取樣產生折線或多邊形，設定最大幾何誤差或最大線段長度。
- 依曲率自適應細分，避免平緩區過度取樣、急彎區精度不足。
- 保留輪廓方向、凹凸關係、洞口與多環邊界；不得只以外接矩形作最終碰撞。
- 測試自交、零長度線段、極短曲線、閉合接縫及狹窄通道。
- 初期可用簡化多邊形作角色碰撞；連續曲線精確碰撞不是第一個切片的必要條件。

## 5. 地形語義
正式 JSON schema 尚待切片驗證，概念上分離：
- path：視覺邊界／輪廓。
- collision：碰撞邊界或碰撞多邊形。
- traversal：可通行區、阻擋區或特殊移動條件。
- surface：地表材質與填充。
- regionType：land、water、rock、cliff、cave、mud、sand 等語義。
- interactionArea：互動區域。
- effects：水波、泡沫、草葉擺動、霧氣等視覺效果，預設不改變碰撞。

水域外觀不自動決定角色能否進入或氧氣規則，需由玩法資料明確指定。

## 6. 渲染與材質
Canvas 2D 負責主要世界場景與路徑繪製；HTML/CSS 繼續負責選單、對話、HUD。使用 Canvas Path／Path2D 繪製輪廓與遮罩。地形填充可使用純色、漸層、重複材質或手繪點陣貼圖；向量路徑與點陣材質可混用。碎石、草叢、泡沫、落葉等裝飾可獨立繪製，預設不參與碰撞。靜態地形可快取；動態水面與粒子維持獨立更新生命週期。

## 7. 俯視 2D 繪製順序
1. 地面底色／大面積地表。
2. 地形區域填充（草地、沙地、泥地、水域）。
3. 地形邊界、岩壁、洞穴輪廓及阻擋物。
4. 固定物件與裝飾。
5. 角色及可移動物件。
6. 樹冠、橋面或需要覆蓋角色的俯視前景層。
7. 水波、泡沫、粒子等效果。
8. UI 由 HTML/CSS 獨立呈現。
此順序不代表 2.5D 深度、視差或高度排序。

## 8. 第一個自然地貌切片
小型測試區包含一段不規則海岸／河岸、一個封閉水域、一段凹角岩壁／洞穴邊界、角色沿邊界移動碰撞、一種地表材質及一項不影響碰撞的裝飾效果。驗收曲線連續、閉合無裂縫、洞口可通行、碰撞與視覺在世界座標對齊，且鏡頭移動／視窗縮放／DPR 改變不造成漂移。桌面瀏覽器實測與效能記錄須獨立執行。

## 9. 分階段路線
- T0：盤點現有幾何與碰撞可重用範圍。
- T1：建立最小 Path Geometry 與 Canvas 繪製，包含直線、二次／三次曲線及封閉輪廓。
- T2：曲線離散化為折線／多邊形，驗證凹角、洞口與狹窄通道。
- T3：整合水域、岸線、岩壁、材質與角色移動，完成自然地貌切片。
- T4：切片通過後才決定正式資料 schema、資產管理與大型場景擴充。

## 10. 暫不處理
2.5D／等角投影／透視傾斜、視差、3D 模型或引擎、完整地圖編輯器、程序化世界生成器、未經測試的通用物理引擎，以及大量正式場景批次製作。

## 11. 待驗證
曲線離散化誤差門檻、多環路徑與洞口支援範圍、材質貼圖規格、靜態快取更新條件、裝飾密度與繪製成本，均須由第一個自然地貌切片驗證。

## 12. T1 實作紀錄（2026-11-11）
**已完成第一版 Path Geometry 基礎 API（不代表曲線碰撞已完成）：**
- `createPathGeometry(commands)`：驗證並建立不可變的純資料路徑。
- 支援 `moveTo`、`lineTo`、`quadraticCurveTo`、`bezierCurveTo`、`arc`、`ellipse`、`closePath`。
- `tracePathGeometry(ctx, geometry)`：將共用路徑資料繪入 Canvas 2D 當前路徑。
- `pathGeometryToPath2D(geometry)`：在瀏覽器提供 Path2D 時轉換為 Path2D。
- `polygonPathGeometry(points)`：將既有多邊形轉為共用路徑資料。
- `buildWall()` 現在保留既有 `verts` 碰撞資料，同時產生 `path`；牆與閘門的輪廓繪製改讀取 path，碰撞、視野與陰影仍沿用原本 verts。
- 此階段不做曲線離散化、曲線碰撞、洞口／多環拓樸、地形 schema 或材質系統；這些仍屬後續階段。
- 參數驗證會拒絕未知命令、非有限座標、負半徑及非 moveTo 起始路徑。
- 本次為程式碼實作與靜態檢查；未完成桌面瀏覽器視覺實測。


## 13. T2 曲線離散化與碰撞整合（2026-11-11）
**已加入第一版曲線離散化與封閉路徑碰撞資料：**
- `flattenPathGeometry(geometry, options)` 將路徑轉成多段世界座標折線，回傳每個子路徑的 points 與 closed 狀態。
- 二次／三次貝茲使用 De Casteljau 遞迴細分，以控制點至弦線的偏差作為平坦度判斷；預設 tolerance 為 0.75 世界單位、最大深度 12。
- 圓弧／橢圓弧依最大半徑與弦高誤差估算取樣數，限制最多 4096 段。
- `pathGeometryToCollisionPolygons()` 只輸出封閉子路徑，保留環順序；碰撞以 even-odd 規則判斷多環區域，支援外環與洞口環的組合。
- `buildWall()` 可接收既有 points 或封閉 path；建立一次 collisionPolygons 與外接範圍，避免每次碰撞重複離散化。
- mvp 碰撞矩形判定已讀取 collisionPolygons，對多環使用 even-odd 點內測試並檢查所有環邊界；洞口內部不會僅因外環包圍而被當成實心區域。
- 視野射線與陰影仍以第一個外環頂點為主；多環視野遮擋及多環陰影不在本次完成範圍。
- 本階段不代表自交輪廓、布林合併、洞口視覺填充、動態曲線編輯或正式自然地形 schema 已完成。


## 14. T3 自然海岸垂直切片第一版（2026-11-11）
**已建立可探索的自然地貌測試切片：**
- 新增不規則沙灘帶與曲線海岸水域；岸線由共用二次／三次曲線 Path Geometry 描述。
- 地形資料先以原型物件分離 `path`、`surface`、`regionType`、`collision`、`traversal` 與視覺 `decorations/ripples`；此格式是切片驗證用，不是最終正式 JSON schema。
- 沙地使用 Canvas 漸層填充及固定位置卵石裝飾；水域使用獨立填充、岸線與靜態水紋。裝飾不參與碰撞。
- 水域偵測由矩形改為共用 Path Geometry 離散化後的多邊形點內測試；水域仍依原玩法規則觸發潛水／氧氣，不因視覺外觀自行改動。
- 新增 C 形曲線岩壁作洞穴邊界，直接以 Path Geometry 建立碰撞多邊形，保留洞口朝西的通行缺口。
- 既有測試物件、角色移動速度、碰撞箱、世界尺寸、互動及存檔規則未調整。
- 本階段尚未完成視野／陰影對曲線洞穴的多環拓樸處理，也未做瀏覽器視覺驗收；切片資料 schema 仍待 T4 再正式化。
