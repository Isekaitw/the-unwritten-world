## 2. MVP 技術預設

| 項目 | 本次採用值 | 備註 |
|---|---|---|
| 世界／投影 | 俯視正交座標；以圖層、霧、光影與地面標記呈現輕量 2.5D | 可回退的原型決策，不鎖死正式美術等角視角 |
| 渲染 | 先用現有 DOM/CSS；場景內容置於可平移的 world 容器 | 不先導入 Canvas 或框架 |
| 世界尺寸 | 1600×1000 世界單位 | 場景大於一般手機視窗，讓鏡頭可跟隨 |
| 玩家 | 一名 CSS 佔位角色；位置用世界座標管理 | 顯示位置與碰撞盒分離 |
| 移動 | WASD／方向鍵；速度預設 180 單位／秒；以時間差更新；對角線正規化 | 不加慣性，先確保操控可預測 |
| 碰撞 | 矩形障礙；角色腳底附近 AABB；X/Y 分軸解析 | 不穿越障礙或場景邊界 |
| 相機 | 角色置中跟隨；clamp 到世界邊界 | 暫不做縮放、死區或複雜平滑 |
| 行動裝置 | 畫面上有方向控制，使用 Pointer Events；按住持續移動，pointerup/cancel、離開控制區、視窗失焦都清除輸入 | 互動按鈕獨立於移動控制 |
| 互動 | 靠近物件顯示提示；E／Enter 或螢幕互動按鈕觸發 | 不用點擊場景代替角色移動 |
| 秘密 | 穩定測試 ID，例如 `test_secret_tide_echo`；首次發現寫入 session 遊戲狀態並顯示回饋 | 同一局不重複發現／發獎 |
| 世界謎題 | 啟動測試機關後，障礙／門的碰撞狀態真的解除 | 必須能走過去，不只是改文字 |
| 存檔 | 不實作 | 重新整理可重置 MVP；第一章才加入存檔 |
| 測試 | 更新 `tests/manual-test-checklist.md`，加入鍵盤、觸控、碰撞、鏡頭、互動、秘密、機關與回歸測試 | 未實際執行的環境不得標通過 |

## 3. 測試區配置

建立一個與正史解耦的測試區。可以視覺上沿用潮汐、遺跡、霧與古代測量裝置的抽象元素，但不要新增正式劇情揭露或改動既有角色動機。

必須有：
1. 出生位置，角色生成時不與障礙重疊。
2. 多個可見矩形障礙，能從至少兩個方向驗證碰撞。
3. 一個靠近後可互動的測試物件，觸發簡短描述／狀態訊息。
4. 一個可發現秘密的區域或物件；首次觸發後顯示已發現狀態，重複互動不重複獎勵。
5. 一道初始封閉的通路及對應機關。啟動機關後，通路外觀改變且碰撞解除，玩家可以實際走過。
6. 狀態列／互動提示；不遮住玩家、移動控制或必要場景區域。
7. 相機可看到出生畫面以外的世界，且移動到邊緣時不露出世界外空白。

## 4. 操作與行為契約

### 桌面
- WASD 與方向鍵均可移動；按鍵放開即停止。
- 對角線速度不得快於水平／垂直移動。
- E 或 Enter 在互動範圍內觸發當前目標；範圍外不能誤觸。
- Escape 關閉對話／提示面板（若面板支援關閉）。
- 返回標題再開始，不得產生重複事件監聽或重複移動迴圈。

### 手機／平板
- 方向控制至少提供上、下、左、右四向，支援持續按住與合理的斜向輸入。
- 使用 `pointerdown`、`pointerup`、`pointercancel` 與失焦清理，不能發生鬆手後角色持續移動。
- 獨立互動按鈕只在有可互動目標時啟用或給出清楚提示。
- 使用安全區域與足夠大的按鈕；不禁用頁面縮放，不以控制層攔截所有非控制區的捲動／點擊。

### 世界、碰撞與鏡頭
- 所有移動與碰撞在同一套世界座標計算；相機只影響顯示，不改變世界位置。
- 先正規化輸入，再乘以速度與時間差。
- 分軸解析碰撞，確保貼牆滑動可行；出生點和場景邊界有效。
- 相機跟隨角色，並將偏移限制在世界範圍；世界比視窗小的軸向應置中而非露空白。
- 互動距離使用世界座標，不使用畫面座標。
- 開門必須同時更新可見狀態與碰撞狀態；秘密採固定 ID 且同一局只記錄一次。

## 5. 建議程式邊界

可保留於少數檔案，避免過度工程化。優先沿用現有 `js/main.js`、`css/main.css`、`index.html`；若確實需要拆檔，新增最少數量並保持單一責任。最低要能辨識下列責任，不強制為每個責任建立獨立檔案：

- 輸入狀態與輸入清理。
- 玩家世界位置與移動。
- 碰撞障礙／場景邊界。
- 相機顯示偏移。
- 互動目標／一次性秘密／機關狀態。
- UI 提示與對話面板。
- 啟停生命週期，避免重複 requestAnimationFrame 或事件監聽。

避免空殼模組、過度抽象、全局狀態四處寫入、每幀重建整個 DOM，以及將劇情內容散落在 CSS 中。

## 6. 驗收清單

- [ ] 開始探索後可直接操控角色，而不是只點擊熱點。
- [ ] 鍵盤方向／WASD 都可移動；放開即停止。
- [ ] 對角線正規化；速度不隨影格率改變。
- [ ] 角色不穿過障礙或世界邊界，貼障礙仍可沿另一軸移動。
- [ ] 相機跟隨且受邊界限制；移動能探索視窗外區域。
- [ ] 手機方向控制可用；取消觸控／離開控制區／失焦不會卡移動。
- [ ] 互動只在範圍內觸發，且提示清楚。
- [ ] 秘密首次記錄一次，重複觸發不重複發獎。
- [ ] 啟動機關後封閉通路實際可通行，並有視覺與文字回饋。
- [ ] 返回標題再進入不重複建立迴圈或監聽器。
- [ ] 保留現有標題、對話與返回流程；Console 無新增未處理錯誤（必須實際檢查才可打勾）。
- [ ] GitHub Pages 子路徑的 CSS／JS／資產引用使用相對路徑。
- [ ] 手動測試清單已更新；未能實測的手機／平板／Pages 項目清楚標「未測試」。

5. 已知限制及下一個最小步驟。
