### 目前原型規則
- 測試世界尺寸 1600×1000。
- 水平視野固定 1200 世界單位；垂直視野依遊戲視窗高度調整。
- 氧氣水下每秒消耗約 100/60，陸地每秒恢復約 100/30。
- 氧氣條在水下顯示；離水後只要氧氣未滿 100% 仍顯示，回滿才隱藏。
- 飢餓、飲水、能量與疲勞目前有 UI／參數入口；不能據此推定完整自動消耗、恢復或生存循環已完成。
- 背包、任務、秘密及測試水域的 ID／數值不自動成為正式章節契約。

## 4. 正式方向與原型的關係
1. 目前測試區是核心移動探索技術的驗證場，不是第一章正式劇情場景。
2. 提前實作的背包、角色參數、任務 UI、氧氣及 localStorage 應保留可重用部分；正式規格尚未定義的行為不得自行視為定案。
3. 若原型數值／UI 與正式企劃衝突，以經確認的正式規格為準；採最小重構，不因既有程式而改寫世界觀或章節。
4. 程式存在不等於功能通過；每項驗收需有日期、commit、裝置／瀏覽器、操作步驟及結果。
